Algorithm

  1. Commitment: before the bet the game shows SHA256(serverSeed) as lowercase hex. Every ball (demo balls included) uses the next nonce of the seed pair, starting from 1.
  2. mac = HMAC-SHA512(key = serverSeed, message = clientSeed + ":" + nonce), as 64 bytes.
  3. Row i = 0 … rows − 1 uses bytes [4i, 4i + 4): x = b0/256 + b1/256² + b2/256³ + b3/256⁴. The ball goes right when x > 0.5, otherwise left.
  4. Slot = number of rights (0 … rows). Multiplier = pay table [risk][rows][bias][slot]; payout = amount × multiplier, truncated to 4 decimals.
  5. Left bias doubles the Classic multiplier on slots with 2 × slot < rows, keeps the middle slot when rows is even, and pays 0 elsewhere. Right is the mirror image. All 27 tables return the same RTP for Classic, Left and Right (≈ 98%).
  6. Nonces used by balls that were rejected by the platform or never confirmed have no settled result, so the settled history of a seed may skip some nonces.
